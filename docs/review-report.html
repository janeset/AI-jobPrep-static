What changed

  • Python from zero removed: its lessons, Home card, sidebar entry, routes, search entries and README section are gone. The AI from zero lessons now say the exercises need a little Python. Old progress on those lessons stays in saved data and exports but isn't shown.
  • Cloud-provider content removed: the AWS Certs tab, AWS and Azure certifications, the AI Cloud Engineer role, and the OpenShift and GPU-in-the-cloud lessons.
  • New Claude & Anthropic track: five courses, four certifications checked on Anthropic's training site, and an eligibility note. No prices are shown.
  • OpenAI Academy section added: four course tracks.
  • Simpler Home: one "Start here" button. Streak and progress cards appear only after the first passed exercise. The local job market is now an optional setting, off by default.
  • Week-1 project added: "First working AI app".
  • Exercises easier to start: each code box now has its instruction above it, and typing on the pass line replaces it.
  • Python runner: it shows a loading message, and it stops after 30 seconds with a clear message.
  • "Last verified" dates are shown on the certifications, course lists, IBM lists and full-course videos.

Kept and rewritten to be provider-neutral (GitHub Actions) instead of deleted.
OpenShift
The Red Hat OpenShift skill stays because it links to the Cloud Prep app. Its lesson was removed.
IBM videos
The GPU and inference videos moved to the Self-hosting lesson. Three news-podcast episodes whose titles named AWS were dropped.

Level choice

Python timeout
Added a 30-second timeout. There was none before, and the acceptance test needed one.
